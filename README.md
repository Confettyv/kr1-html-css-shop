## Описание проекта

«Мипл» — многостраничный сайт магазина настольных игр. В каталоге восемь
товаров с ценами, временем партии и числом игроков; есть отдельная страница
категории со сравнительной таблицей, карточка товара с характеристиками,
форма заявки, страница контактов с формой обратной связи и раздел частых
вопросов.

Проект выполнен без CSS-фреймворков. JavaScript используется только для
открытия и закрытия модального окна — это около двадцати строк в
`js/main.js`. Всё остальное оформление сделано средствами HTML и CSS.

## Обязательные страницы

| Страница | Содержание |
|---|---|
| `index.html` | Первый экран с описанием магазина, блок преимуществ (`#advantages`), популярные игры (`#popular`), отзывы покупателей |
| `catalog.html` | Каталог из восьми карточек, боковой блок фильтров, переключатель категорий, модальное окно подбора |
| `product.html` | Карточка игры «Долина ветров»: изображение, описание, краткие факты, таблица характеристик, кнопки заявки, блок сопутствующих товаров |
| `order.html` | Форма заявки: имя, почта, телефон, выбор игры, способ получения, дата, комментарий, согласие на обработку данных |
| `contacts.html` | Адрес, телефон, часы работы, игровая зона и форма обратной связи |

Дополнительно добавлены две страницы сверх обязательного списка:
`category.html` (отдельная категория со сравнительной таблицей) и
`faq.html` (вопросы и ответы).

## Используемые технологии

- HTML5, семантические теги `header`, `nav`, `main`, `section`, `article`,
  `aside`, `footer`;
- CSS3: пользовательские свойства (`:root`), Flexbox, CSS Grid,
  позиционирование `relative` / `absolute` / `sticky` / `fixed`, `z-index`,
  медиазапросы, `prefers-color-scheme`, `prefers-reduced-motion`;
- БЭМ для именования классов;
- элемент `<dialog>` для модального окна;
- шрифты Bitter и Golos Text с Google Fonts;
- изображения в формате SVG, подготовлены для проекта.

## Самостоятельные доработки

Сверх пошаговых требований методических указаний в проект добавлено следующее.

**Структура**

- две дополнительные страницы: категория `category.html` и раздел вопросов
  `faq.html`;
- блок отзывов на главной странице;
- блок сопутствующих товаров на карточке товара;
- хлебные крошки на всех внутренних страницах.

**Оформление**

- собственная визуальная концепция: зелёная палитра сукна игрового стола,
  слэб-серифный заголовочный шрифт Bitter и наборный Golos Text;
- тёмная тема по системной настройке через `prefers-color-scheme`, все цвета
  вынесены в переменные и переопределяются одним блоком;
- все изображения нарисованы для проекта в SVG: логотип, иллюстрация первого
  экрана и восемь обложек игр — растровых файлов в репозитории нет.

**Карточки и каталог**

- три варианта бейджа через модификаторы БЭМ:
  `product-card__badge--hit`, `--new`, `--sale`;
- модификатор `product-card--discount` меняет цвет цены и показывает
  зачёркнутую старую цену;
- в карточке выводятся число игроков, время партии и возраст;
- состояния `:hover` и `:focus-within` у карточки, чтобы подсветка появлялась
  и при переходе по карточке с клавиатуры;
- липкий боковой блок фильтров (`position: sticky`) и переключатель
  категорий в виде чипсов.

**Формы и модальное окно**

- модальное окно на `<dialog>` закрывается крестиком, кнопкой «Отмена»,
  клавишей Esc и кликом по затемнённой области;
- в форме заявки есть подсказки под полями, выбор способа получения и даты,
  кнопка сброса;
- у каждого поля подпись `label`, совпадающие `for` и `id`, атрибуты `name`,
  обязательные поля помечены `required` и звёздочкой, почта проверяется через
  `type="email"`, телефон — через `pattern`.

**Доступность**

- ссылка «К основному содержимому» для перехода с клавиатуры;
- видимый фокус у всех интерактивных элементов через `:focus-visible`;
- `aria-current="page"` у активного пункта меню, подписи `aria-label`
  у навигации и кнопок-иконок;
- контраст текста и фона выдержан в обеих темах;
- отключение анимаций при `prefers-reduced-motion`.

**Код**

- единый файл стилей разбит на пронумерованные разделы;
- БЭМ применён последовательно: блок, элемент через `__`, модификатор
  через `--`;
- повторяющиеся значения вынесены в переменные `:root`, дублирование цветов
  и отступов в правилах отсутствует.
